Project documentation

Project Overview

AI Placement & Career Assistant Using RAG, LangChain and Prompt Engineering.

Problem statement

Students often struggle to identify suitable job opportunities, understand skill gaps and prepare for placement interviews using scattered resources. This project proposes an integrated AI-assisted platform for resume analysis, job matching, interview preparation and personalized career guidance.

Objectives

  • Analyze resumes and extract relevant profile information.
  • Compare student skills with job requirements.
  • Identify missing competencies and recommend learning topics.
  • Generate role-specific interview practice.
  • Use prompt techniques to improve output structure and relevance.
  • Use RAG to ground responses in career-related documents.
